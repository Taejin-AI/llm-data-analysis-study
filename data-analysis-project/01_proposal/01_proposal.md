# 1차 과제 제안서 (Proposal)

## 1. 프로젝트 제목
현대자동차그룹 채용공고 분석을 통한 기술 분야 교육과정 수요 도출 및 시장 교육과정 공백(Gap) 분석

---

## 2. 프로젝트 배경 및 목적

### 2.1 배경
저는 현대자동차그룹의 기술교육 전문회사인 현대엔지비(HYUNDAI NGV)에서 근무하고 있으며,
그룹 구성원을 대상으로 하는 직무기술 교육과정을 기획하고 운영하는 일을 맡고 있습니다.

최근 자동차 산업은 SDV(Software Defined Vehicle), 자율주행, 전동화, 로보틱스, 생성형 AI를
중심으로 빠르게 바뀌고 있습니다. 그만큼 그룹사 현장에서 요구하는 기술 역량도 함께 달라지고
있는데, 막상 교육과정을 기획할 때는 담당자의 경험이나 설문에 의존하는 경우가 많습니다.
그러다 보니 현장이 실제로 필요로 하는 기술과 우리가 제공하는 교육과정 사이에 어느 정도
간극이 있는지를 데이터로 확인하기가 쉽지 않았습니다.

채용공고는 기업이 지금 당장 필요로 하는 인재의 역량을 가장 직접적으로 드러내는 자료라고
생각합니다. 그래서 그룹사 채용공고를 모아서 분석하면 현장의 기술 수요를 비교적 객관적으로
파악할 수 있고, 이를 시중 교육과정 현황과 비교해 보면 어떤 교육을 새로 만들어야 할지에 대한
근거를 마련할 수 있을 것으로 기대합니다.

### 2.2 분석 대상 및 목적
분석 대상은 그룹 내에서 기술 직군 채용이 활발한 11개 그룹사로 선정했습니다. 완성차의
현대자동차·기아, 부품과 모듈을 담당하는 현대모비스·현대위아·현대트랜시스·현대케피코,
소재의 현대제철, 로보틱스·방산·철도 분야의 현대로템, 물류의 현대글로비스, 금융의
현대캐피탈, 그리고 그룹 IT와 소프트웨어를 맡고 있는 현대오토에버입니다. 완성차부터
부품·소재·물류·금융·IT까지 폭넓게 걸쳐 있어서, 데이터 분석·AI·Physical AI(로보틱스
포함)·SW·IT 다섯 개 기술 분야의 수요를 고르게 살펴볼 수 있다고 판단했습니다.

이 11개 그룹사를 대상으로 다음을 진행하려고 합니다.

1. 11개 그룹사의 채용공고를 수집해, 데이터 분석·AI·Physical AI·SW·IT 다섯 개 분야별로
   요구되는 역량과 기술스택을 정리합니다.
2. 그룹사별, 직무별로 요구 기술에 어떤 차이가 있는지 비교합니다.
3. 시중의 기술교육과정(온라인 강의 플랫폼, 부트캠프, K-디지털 트레이닝 등)을 조사해
   인기 있는 과정과 수강 수요가 높은 영역을 파악합니다.
4. 채용 수요(1~2번)와 교육 공급(3번)을 비교해, 수요는 높지만 교육 공급이 부족한
   공백(Gap) 영역을 찾고, 현대엔지비가 새 교육과정을 기획할 때의 우선순위를 제안합니다.

### 2.3 활용처
- 현대엔지비 교육기획 담당: 신규 직무교육과정 개발과 커리큘럼 우선순위를 정하는 근거로 활용
- 그룹사 인사·HRD 담당: 인력 확보가 어려운 기술 분야를 사내에서 양성하는 전략 수립에 참고
- 개인적으로는 데이터에 기반해 교육을 기획하는 역량을 키우는 계기로 삼고자 합니다.

## 3. 핵심 분석 질문
데이터로 확인하고 싶은 질문은 다음과 같습니다.

1. (수요 파악) 11개 그룹사 채용공고에서 데이터 분석·AI·Physical AI·SW·IT 다섯 개 분야별로
   가장 많이 요구되는 기술과 역량은 무엇인가요? (예: Python, 클라우드, 머신러닝, ROS,
   임베디드 등)
2. (차이 비교) 그룹사별, 직무군별로 요구하는 기술에는 어떤 차이가 있나요? 예를 들어
   현대로템·현대위아는 로보틱스나 제어, 현대오토에버는 SW·클라우드·데이터, 현대캐피탈은
   금융 데이터·AI에 수요가 몰릴 것으로 예상되는데, 이런 가설을 데이터로 확인하려고 합니다.
3. (시장 공급) 시중 기술교육과정 중 수강생 수나 평점 기준으로 인기가 높은 과정은
   무엇이고, 교육 공급이 어느 분야에 집중되어 있나요?
4. (Gap 도출) 채용에서 요구되는 기술에 비해 시중 교육과정이 충분히 다루지 못하는 공백
   영역은 무엇인가요? 현대엔지비가 먼저 개설하면 좋을 교육과정은 무엇인가요?

이 프로젝트의 핵심 가설은 "채용 수요가 높은 기술과 교육 공급이 많은 기술이 서로
일치하지 않으며, 그 불일치 영역이 사내 교육으로 메워야 할 우선 과제"라는 것입니다.

## 4. 데이터 확보 계획
데이터는 크게 (A) 채용공고 데이터와 (B) 교육과정 데이터 두 축으로 확보하려고 합니다.

### 4.1 (A) 채용공고 데이터

| 항목 | 내용 |
|------|------|
| 출처 | 현대자동차그룹 통합 채용포털, 채용 플랫폼(사람인·잡코리아·원티드·점핏), 공공데이터 |
| 접근 방법 | 공식 채용 페이지 및 플랫폼 웹 크롤링, 공공 API |
| 예상 규모 | 11개 그룹사 × 직무공고 수십~수백 건, 수집 기간 누적 약 500~1,500건 |
| 주요 변수 | 회사명, 직무명, 직무분류, 근무지, 자격요건, 우대사항, 사용기술/스택, 경력요건, 공고일 |
| 확보 가능 여부 | 가능 (공개된 공고 텍스트 기준) |

세부적으로는 아래 출처를 함께 활용할 계획입니다.

- 공공데이터포털과 고용24(워크넷)의 채용정보 Open API: 정부가 제공하는 공식 API라 비교적
  안정적으로 수집할 수 있습니다. (https://www.data.go.kr , https://www.work24.go.kr)
- 원티드, 점핏: IT·개발 직무가 많고 기술스택이 태그로 정리되어 있어 기술 키워드를 뽑기에
  유리합니다.
- 사람인, 잡코리아: 그룹사의 전 직군을 폭넓게 다루기 위해 사용합니다.
- 현대자동차그룹 채용 사이트: 자격요건과 우대사항 원문 텍스트를 확보합니다.

수집할 때는 각 사이트의 robots.txt와 이용약관을 먼저 확인하고, API가 제공되는 곳은 API를
우선 사용하겠습니다. 요청이 한꺼번에 몰리지 않도록 간격을 두고, 지원자 개인정보는 수집하지
않으며 공개된 공고 텍스트만 다루려고 합니다. 저작권 문제를 피하기 위해 원문을 그대로
재배포하지 않고 분석에 필요한 키워드와 통계만 산출할 예정입니다.

### 4.2 (B) 교육과정 데이터

| 항목 | 내용 |
|------|------|
| 출처 | 온라인 강의 플랫폼(인프런·패스트캠퍼스·유데미·코드잇), 부트캠프, HRD-Net(직업훈련포털) |
| 접근 방법 | 플랫폼 공개 강의목록 크롤링, HRD-Net 공공데이터 |
| 예상 규모 | 데이터·AI·SW·IT 카테고리 강의 수백~수천 건 |
| 주요 변수 | 과정명, 카테고리, 가격, 수강생 수, 평점/리뷰 수, 난이도, 주요 키워드, 운영기관 |
| 확보 가능 여부 | 가능 (수강생 수·평점 등 인기 지표가 공개되어 있음) |

- 인프런: 강의별 수강생 수, 별점, 수강평 수가 공개되어 있어 인기 과정을 가늠하기에 적합합니다.
- 패스트캠퍼스, 코드잇, 유데미: 데이터·AI·개발 분야 커리큘럼을 비교하는 데 활용합니다.
- HRD-Net 직업훈련포털(고용노동부): K-디지털 트레이닝 등 국비 교육과정 목록과 정원,
  훈련기관 정보를 공공데이터로 제공하므로, 국가 차원의 교육 공급 현황을 함께 보려고 합니다.

교육 플랫폼 역시 robots.txt와 이용약관을 지키고, 공개된 과정 메타데이터만 수집하겠습니다.

### 4.3 이 데이터로 분석 질문에 답할 수 있는가
- 채용공고의 자격요건·우대사항·기술스택 텍스트로 질문 1·2(수요와 차이)에 답할 수 있습니다.
- 교육과정의 카테고리·수강생 수·평점으로 질문 3(인기와 공급)에 답할 수 있습니다.
- 두 데이터셋의 기술 키워드를 공통 스킬 사전으로 맞춰 비교하면 질문 4(Gap)에 답할 수 있습니다.

## 6. 예상 분석 방법
분석 질문에 맞춰 아래 방법을 단계적으로 적용하려고 합니다. 방법을 많이 쓰기보다 질문에
맞는 방법을 고르는 데 중점을 두겠습니다.

1. 데이터 전처리: 중복 공고 제거, 결측 처리, 직무명·회사명 표준화
2. 텍스트 분석(핵심): 한국어 형태소 분석(KoNLPy 등)과 영문 기술 키워드 추출, 스킬 사전을
   활용한 키워드 정규화와 5대 분야 태깅, TF-IDF로 분야·회사별 핵심 기술 도출
3. 기술통계와 빈도 분석: 기술 키워드 빈도, 분야별 공고 비중
4. 그룹별 비교 분석: 그룹사별, 직무군별 요구 기술 교차 비교
5. 시각화: 막대그래프, 히트맵(회사 × 기술), 워드클라우드, 버블차트(수요 vs 공급)
6. 토픽 모델링(LDA): 채용공고 안에 있는 잠재적인 직무 테마 도출 (여유가 되면 심화로 진행)
7. Gap 분석(핵심 산출물): 채용 수요 상위 기술과 교육 공급(인기 과정) 상위 기술의 순위를
   비교하고, 수요와 공급을 각각 높음/낮음으로 나눈 2×2 매트릭스에서 "수요는 높은데 공급이
   낮은" 영역을 공백 교육과정으로 식별

## 7. 생성형 AI 활용 계획
ChatGPT, Claude, Gemini, Copilot 등을 아래 단계에서 보조 도구로 활용하려고 합니다.

| 단계 | AI 활용 내용 |
|------|-------------|
| 질문 구체화 | 분석 질문과 가설을 다듬고, 분야 분류 체계를 검토 |
| 데이터 수집 | 크롤링·API 호출 코드 작성, robots.txt 준수 로직 점검 |
| 키워드 추출 | 자유 서술형 자격요건 텍스트에서 기술 키워드를 추출·분류 |
| 전처리·EDA | 결측·이상치 처리 코드, EDA 템플릿 작성 |
| 시각화 | matplotlib·seaborn·plotly 시각화 코드 초안 작성 |
| 결과 해석 | 분석 결과에 대한 다른 해석 검토, 보고서 문장 다듬기 |

다만 AI가 만들어 준 코드나 키워드 분류, 해석은 반드시 실제 데이터와 실행 결과를 기준으로
직접 확인하겠습니다. 특히 LLM으로 기술 키워드를 태깅할 때는, 표본을 직접 라벨링한 결과와
비교해 정확도를 점검한 뒤에 사용할 생각입니다.

## 8. 향후 진행 계획
대략 아래 순서로 진행하려고 합니다.

1. 데이터 확보: 채용공고와 교육과정 수집 파이프라인 구축 (API 우선, 부족한 부분은 크롤링 보완)
2. 구조·품질 확인: 컬럼 정의 확정, 수집량과 결측 점검, 스킬 사전 초안 작성
3. 전처리: 표준화, 중복 제거, 키워드 추출과 분야 태깅
4. 탐색적 데이터 분석(EDA): 분야별·그룹사별 빈도와 분포 파악, 1차 시각화
5. 본 분석: TF-IDF, 그룹 비교, (선택) 토픽 모델링으로 수요 순위 산출
6. Gap 분석과 검증: 수요 vs 공급 매트릭스 작성, 공백 교육과정 도출과 타당성 검토
7. 인사이트와 시각화: 신규 교육과정 우선순위 제안, 대시보드 형태로 정리
8. 최종 결과물: 분석 노트북과 보고서, 그리고 Streamlit을 활용한 결과 전달

최종적으로는 분석 노트북과 보고서, 그룹사별 요구기술을 보여 주는 대시보드, 그리고
수요는 높지만 공급이 부족한 영역을 바탕으로 한 현대엔지비 신규 교육과정 우선순위 제안을
정리하는 것을 목표로 하고 있습니다.

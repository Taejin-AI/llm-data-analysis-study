# 1차 과제 제안서 (Proposal)

## 1. 프로젝트 제목
**현대자동차그룹 채용공고 분석을 통한 기술 분야 교육과정 수요 도출 및 시장 교육과정 공백(Gap) 분석**

---

## 2. 프로젝트 배경 및 목적

### 2.1 배경
본인은 현대자동차그룹의 기술교육 전문회사인 **현대엔지비(HYUNDAI NGV)** 에 재직 중이며,
그룹 구성원을 대상으로 한 직무기술 교육과정을 기획·운영하는 업무를 담당하고 있다.

최근 자동차 산업은 **SDV(Software Defined Vehicle), 자율주행, 전동화, 로보틱스, 생성형 AI**
로 급격히 전환되고 있으며, 이에 따라 그룹사 각 현장에서 요구하는 기술 역량도 빠르게
변화하고 있다. 그러나 교육과정 기획은 여전히 담당자의 경험과 설문에 의존하는 경우가 많아,
**"현장이 실제로 채용·요구하는 기술"과 "제공되는 교육과정" 사이의 간극**을 데이터로
객관화하기 어려운 상황이다.

채용공고는 기업이 "지금 당장 필요로 하는 인재의 역량"을 가장 직접적으로 드러내는 텍스트
데이터이다. 따라서 그룹사 채용공고를 분석하면 현장 기술 수요를 비교적 객관적으로 파악할 수
있고, 이를 시중 교육과정 현황과 비교하면 **어떤 교육을 신규로 개설해야 하는지** 에 대한
근거를 마련할 수 있다.

### 2.2 목적
1. 현대자동차그룹 주요 11개 그룹사의 채용공고를 수집하여, **데이터 분석 · AI ·
   Physical AI(로보틱스 포함) · SW · IT** 5개 기술 분야별로 요구 역량·기술스택을 정량화한다.
2. 그룹사별·직무별 요구 기술의 차이를 비교 분석한다.
3. 시중 기술교육과정(온라인 강의 플랫폼, 부트캠프, K-디지털 트레이닝 등)을 조사하여
   **인기 교육과정**과 수강 수요가 높은 영역을 파악한다.
4. 채용 수요(1~2)와 교육 공급(3)을 비교하여, 수요는 높으나 교육 공급이 부족한
   **공백(Gap) 교육과정**을 도출하고, 현대엔지비 신규 교육과정 기획의 우선순위를 제안한다.

### 2.3 활용처
- **현대엔지비 교육기획팀**: 신규 직무교육과정 개발 및 커리큘럼 우선순위 수립 근거
- **그룹사 인사/HRD 담당**: 인력 확보가 어려운 기술 분야에 대한 사내 양성 전략
- 본인: 데이터 기반 교육기획 역량 강화

## 3. 핵심 분석 질문

1. **[수요 파악]** 11개 그룹사 채용공고에서 데이터 분석 · AI · Physical AI · SW · IT
   5개 분야별로 가장 많이 요구되는 기술·역량·툴(예: Python, 클라우드, 머신러닝,
   ROS, 임베디드 등)은 무엇인가?
2. **[차이 비교]** 그룹사별·직무군별로 요구 기술에 어떤 차이가 있는가?
   (예: 현대로템·현대위아는 로보틱스/제어, 현대오토에버는 SW/클라우드/데이터,
   현대캐피탈은 금융 AI/데이터 분석 등 — 가설을 데이터로 검증)
3. **[시장 공급]** 시중 기술교육과정 중 인기(수강생 수·평점 기준)가 높은 과정은 무엇이며,
   어떤 기술 분야에 교육 공급이 집중되어 있는가?
4. **[Gap 도출]** 채용에서 요구되는 기술 대비, 시중 교육과정이 충분히 다루지 않는
   **공백 영역**은 무엇인가? 현대엔지비가 우선 개설해야 할 교육과정은 무엇인가?

> 본 과제의 핵심 가설: *"채용 수요 상위 기술과 교육 공급 상위 기술은 일치하지 않으며,
> 그 불일치 영역이 사내 교육으로 메워야 할 우선 과제이다."*

## 4. 데이터 확보 계획

본 프로젝트는 크게 **(A) 채용공고 데이터**와 **(B) 교육과정 데이터** 두 축으로 데이터를
확보한다.

### 4.1 (A) 채용공고 데이터

| 항목 | 내용 |
|------|------|
| 출처 | ① 현대자동차그룹 통합 채용포털, ② 채용 플랫폼(사람인·잡코리아·원티드·점핏), ③ 공공데이터 |
| 접근 방법 | 공식 채용 페이지 및 플랫폼 웹 크롤링 + 공공 API |
| 예상 규모 | 11개 그룹사 × 직무공고 수십~수백 건 → **총 약 500~1,500건** (수집 기간 누적) |
| 주요 변수 | 회사명, 직무명, 직무분류, 근무지, 자격요건, 우대사항, 사용기술/스택, 경력요건, 공고일 |
| 확보 가능 여부 | ✅ 가능 (아래 주석 참조) |

**세부 출처**
- **공공데이터포털 / 고용24(워크넷) 채용정보 API**: 정부 공식 채용정보 Open API로 안정적
  수집 가능. (https://www.data.go.kr , https://www.work24.go.kr)
- **원티드(Wanted)·점핏(Jumpit)**: IT·개발 직무 중심, 기술스택(태그)이 구조화되어 있어
  기술 키워드 추출에 유리.
- **사람인·잡코리아**: 그룹사 전 직군 커버리지 확보용.
- **현대자동차그룹 채용 사이트(talent.hyundai.com 등)**: 공고 원문(자격요건·우대사항)
  텍스트 확보.

> ⚠️ **수집 윤리·법적 준수**: 각 사이트의 `robots.txt`·이용약관을 확인하고, API가 제공되는
> 경우 API를 우선 사용한다. 과도한 요청을 피하기 위해 요청 간 지연(delay)을 두고,
> 개인정보(지원자 정보 등)는 수집하지 않으며 **공개된 공고 텍스트만** 수집한다.
> 저작권 이슈를 피하기 위해 원문 재배포 없이 분석용 키워드/통계만 산출한다.

### 4.2 (B) 교육과정 데이터

| 항목 | 내용 |
|------|------|
| 출처 | 온라인 강의 플랫폼(인프런·패스트캠퍼스·유데미·코드잇), 부트캠프, HRD-Net(직업훈련포털) |
| 접근 방법 | 플랫폼 공개 강의목록 크롤링 + HRD-Net 공공데이터 |
| 예상 규모 | 데이터/AI/SW/IT 카테고리 강의 **수백~수천 건** |
| 주요 변수 | 과정명, 카테고리, 가격, 수강생 수, 평점/리뷰 수, 난이도, 주요 키워드, 운영기관 |
| 확보 가능 여부 | ✅ 가능 (인기 지표인 수강생 수·평점이 공개됨) |

**세부 출처**
- **인프런(Inflearn)**: 강의별 수강생 수·별점·수강평 수가 공개되어 **"인기 과정"** 지표
  산출에 적합.
- **패스트캠퍼스 / 코드잇 / 유데미**: 데이터/AI/개발 분야 커리큘럼 비교.
- **HRD-Net 직업훈련포털(고용노동부)**: K-디지털 트레이닝(KDT) 등 국비 교육과정 목록·
  정원·훈련기관을 공공데이터로 제공 → 국가 차원 교육 공급 현황 파악.

> ⚠️ 교육 플랫폼 역시 `robots.txt`·이용약관을 준수하고, 공개된 과정 메타데이터만 수집한다.

### 4.3 데이터로 분석 질문에 답할 수 있는가?
- 채용공고의 **자격요건·우대사항·기술스택** 텍스트 → 질문 1·2(수요·차이)에 답 가능
- 교육과정의 **카테고리·수강생 수·평점** → 질문 3(인기·공급)에 답 가능
- 두 데이터셋의 기술 키워드를 **공통 스킬 사전**으로 매핑·비교 → 질문 4(Gap)에 답 가능

## 6. 예상 분석 방법

분석 질문에 맞추어 다음 방법을 단계적으로 적용할 예정이다. (방법의 수보다 질문 적합성을 우선)

1. **데이터 전처리**: 중복 공고 제거, 결측 처리, 직무명·회사명 표준화
2. **텍스트 분석(핵심)**
   - 한국어 형태소 분석(KoNLPy 등) + 영문 기술 키워드 추출
   - 기술 스킬 사전 기반 키워드 정규화 및 5대 분야 태깅
   - TF-IDF로 분야·회사별 핵심 기술 도출
3. **기술통계·빈도 분석**: 기술 키워드 빈도, 분야별 공고 비중
4. **그룹별 비교 분석**: 그룹사별·직무군별 요구 기술 교차 비교
5. **시각화**: 막대그래프, 히트맵(회사 × 기술), 워드클라우드, 버블차트(수요 vs 공급)
6. **(심화, 선택) 토픽 모델링(LDA)**: 채용공고 내 잠재 직무 테마 도출
7. **Gap 분석(핵심 산출물)**
   - 채용 수요 상위 기술 순위 vs 교육 공급(인기 과정) 상위 기술 순위 비교
   - 2×2 매트릭스(수요 高/低 × 공급 高/低)로 **"수요 高 · 공급 低" = 공백 교육과정** 식별

## 7. 생성형 AI 활용 계획

ChatGPT, Claude, Gemini, Copilot 등을 다음 단계에서 보조 도구로 활용한다.

| 단계 | AI 활용 내용 |
|------|-------------|
| 질문 구체화 | 분석 질문·가설 정교화, 분야 분류 체계 설계 검토 |
| 데이터 수집 | 크롤링/ API 호출 코드 작성, `robots.txt` 준수 로직 검토 |
| 키워드 추출 | 비정형 자격요건 텍스트에서 기술 키워드 추출·분류 (LLM 기반 태깅) |
| 전처리·EDA | 결측/이상치 처리 코드, EDA 템플릿 생성 |
| 시각화 | matplotlib/seaborn/plotly 시각화 코드 초안 |
| 결과 해석 | 분석 결과의 대안적 해석·검토, 보고서 문장 다듬기 |

> ✅ **검증 원칙**: AI가 생성한 코드·키워드 분류·해석은 반드시 **실제 데이터와 실행 결과**를
> 기준으로 직접 확인한다. 특히 LLM 기반 기술 키워드 태깅은 표본을 직접 라벨링한 결과와
> 비교하여 정확도를 점검한 뒤 사용한다.

## 8. 향후 진행 계획

```
[1단계] 데이터 확보       : 채용공고·교육과정 수집 파이프라인 구축 (API 우선, 크롤링 보완)
   ↓
[2단계] 구조·품질 확인    : 컬럼 정의 확정, 수집량·결측 점검, 스킬 사전 초안 작성
   ↓
[3단계] 전처리           : 표준화, 중복 제거, 키워드 추출·분야 태깅
   ↓
[4단계] 탐색적 분석(EDA)  : 분야별·그룹사별 빈도/분포 파악, 1차 시각화
   ↓
[5단계] 본 분석          : TF-IDF·그룹 비교·(선택)토픽모델링, 수요 순위 산출
   ↓
[6단계] Gap 분석·검증    : 수요 vs 공급 매트릭스, 공백 교육과정 도출 및 타당성 검토
   ↓
[7단계] 인사이트·시각화   : 신규 교육과정 우선순위 제안, 대시보드화
   ↓
[8단계] 최종 결과물      : 분석 노트북 + 보고서 + Streamlit 결과 전달
```

**예상 산출물**: 분석 Notebook, 분석 보고서, 그룹사별 요구기술 대시보드,
그리고 **현대엔지비 신규 교육과정 우선순위 제안서**(수요 高·공급 低 영역 기반).

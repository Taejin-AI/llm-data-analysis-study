# 현대자동차그룹 채용공고 기반 기술교육과정 도출 프로젝트

2026 데이터분석 프로젝트 (현대엔지비 직무교육 기획 관점)

## 프로젝트 개요
현대자동차그룹 주요 11개 그룹사의 채용공고를 수집하고 분석해서, 현장이 실제로 요구하는
기술 역량(데이터 분석, AI, Physical AI(로보틱스), SW, IT)을 도출합니다. 이를 시중
기술교육과정 현황과 비교해, 수요는 높지만 공급이 부족한 영역을 찾아 신규 교육과정을
제안하는 것을 목표로 합니다.
